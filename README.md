# org_enums

Shared `StrEnum` definitions for your projects.

## Install (from GitHub tag)
```bash
uv add 'org_enums @ git+https://github.com/YourOrg/org_enums@v0.1.0'
```

## Import
```python
from org_enums.power_controller import *   # all PowerController enums
from org_enums.scheduling import *         # all Scheduling enums
from org_enums import *                    # aggregate (same set, explicit)
```
